# 형식 선택 UI 개선 계획서

작성일: 2026-11-21

## 1. 문제
- 출력 형식이 55개로 늘어서 드롭다운(콤보박스) 하나에 전부 넣으면 목록이 모니터 아래로 넘어간다.
- 대부분의 사용자는 MP4, MP3, PNG, JPG 같은 자주 쓰는 형식 몇 개만 쓰는데, 매번 긴 목록에서 찾아야 한다.
- 원래 목표인 "클릭 한 번으로 간단하게"가 흐려졌다.

## 2. 목표
1. 자주 쓰는 형식은 **목록을 열지 않고 바로 클릭**해서 고른다.
2. 55개 전체는 유지하되 **필요할 때만** 펼쳐 보게 한다.
3. 목록이 화면 밖으로 넘어가지 않는다.
4. 파일을 넣으면 알맞은 종류(영상/오디오/이미지)가 자동으로 정해진다.

## 3. 후보안 비교
| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A | 종류 탭 + 드롭다운 | 구현 쉬움 | 영상 탭도 20개라 여전히 길고, 클릭이 2번 |
| B | 자주 쓰는 형식 버튼(칩) + [더보기] 펼침 | 대부분 클릭 1번, 화면에 안 넘침 | 칩 레이아웃(줄바꿈) 구현 필요 |
| C | 형식 선택 전용 팝업 창 | 전체를 한눈에 | 클릭 늘고 앱이 무거워 보임 |

**채택: B안** (A의 종류 구분을 함께 사용)

## 4. 화면 설계 (B안)
```
바꿀 형식   [ MP4 ] [ MKV ] [ WebM ] [ MOV ] [ AVI ] [ GIF ]  [ 더보기 ▾ ]
                                                      [ 바꾸기 ]

(더보기를 누르면 아래에 나머지 형식이 줄바꿈된 칩으로 펼쳐짐)
M4V WMV ASF FLV 3GP 3G2 TS MTS M2TS MPG MPEG VOB OGV APNG
```
- 칩은 눌린 상태가 유지되는 토글 버튼(하나만 선택). 선택된 칩은 민트색으로 표시한다.
- 자주 쓰는 형식(칩으로 항상 표시)
  - 영상: MP4, MKV, WebM, MOV, AVI, GIF
  - 오디오: MP3, WAV, FLAC, M4A, OGG, OPUS
  - 이미지: PNG, JPG, WebP, BMP, TIFF, ICO
- 나머지는 [더보기]를 눌렀을 때만 보인다. 영상/오디오/이미지 머리글 아래에 칩으로 나열해 한 화면 안에서 끝낸다.
- 더보기에서 형식을 고르면 그 칩이 선택 상태가 되고, 패널은 접어서 선택한 형식만 남긴다.

## 5. 동작 규칙
- 파일이 없으면 영상 칩을 기본으로 보여 준다.
- 파일을 넣으면 그 종류만 보여 준다. 영상 파일이면 영상+오디오 형식, 이미지 파일이면 이미지 형식, 오디오 파일이면 오디오 형식.
- 여러 종류를 섞어 넣으면 각 종류의 자주 쓰는 칩을 종류 머리글과 함께 모두 보여 준다.
- 기본 선택값: 영상 → MP4, 오디오 → MP3, 이미지 → PNG. 이전에 고른 형식이 새 목록에도 있으면 유지한다.
- 마지막으로 고른 형식을 저장해 다음 실행 때 기억한다(선택 기능).
- 현재 드롭다운에 쓰는 가능 여부 판단 코드(`can_convert`)는 그대로 재사용한다.

## 6. 구현 단계
| 단계 | 내용 | 파일 |
|---|---|---|
| 1 | `FORMATS`에 "자주 쓰는 형식" 표시 추가 (POPULAR 목록) | `core/simple.py` |
| 2 | 줄바꿈 되는 칩 레이아웃(FlowLayout) 위젯, 칩 버튼 위젯 작성 | `ui/format_picker.py` (신규) |
| 3 | 메인 화면의 콤보박스를 `FormatPicker`로 교체, 선택값을 `current()`로 노출 | `ui/main_window.py` |
| 4 | 칩 스타일(선택 시 민트, 호버 시 초록 테두리) 추가 | `ui/theme.py` |
| 5 | 파일 변경 시 칩 목록 갱신, 더보기 펼침/접힘 | `ui/format_picker.py` |
| 6 | 화면 확인(빈 상태/영상/오디오/이미지/혼합), 작은 창에서도 넘침 없는지 확인 | 스크린샷 검증 |
| 7 | 테스트 갱신(변환 테스트는 그대로, 목록 필터링 단위 테스트 추가) | `tests/` |

예상 작업량: 코드 약 150줄, 반나절 이내.

## 7. 임시 응급 처치 (선택)
계획이 반영되기 전까지 드롭다운의 `setMaxVisibleItems`를 10 정도로 낮추면 목록이 화면 밖으로 안 넘치고 스크롤된다. 한 줄 수정이다.

## 8. 위험 요소와 대응
| 위험 | 대응 |
|---|---|
| 창을 좁히면 칩이 넘침 | 줄바꿈 레이아웃이라 자동으로 다음 줄로 내려감. 최소 창 너비 설정 |
| 형식을 못 찾겠다는 사용자 | [더보기] 안에 전체 형식을 종류별로 유지, 검색 기능은 필요 시 후속 과제 |
| 혼합 종류에서 화면이 복잡해짐 | 종류 머리글로 구분하고, 해당 파일에 맞는 칩만 활성화 |

## 9. 확정이 필요한 사항
1. B안(칩 + 더보기)으로 진행할지
2. 자주 쓰는 형식 목록(위 6개씩)이 맞는지, 바꿀 형식이 있는지
3. 마지막 선택 형식을 기억할지
